# 성현교회 재정 (v0.2.14)

주일 헌금 현황과 연간 예결산을 관리하는 Windows 프로그램입니다. 헌금·재정 데이터는 **이 PC에만** 저장되고, 프로그램 업데이트만 GitHub로 받습니다. (출석부 앱과 같은 방식)

## 1. 설치
1. GitHub 저장소 **Releases**에서 `SeonghyeonFinance-Setup-x.y.z.exe`를 받아 설치합니다. (처음 올리는 방법은 4번)
2. Windows 보호 창이 뜨면 *추가 정보 → 실행*. 이후 업데이트는 자동입니다.

데이터: `문서\성현교회재정\data.json` (하루 한 번 `백업` 폴더에 사본, 90일 보관). 메뉴 *파일 → 데이터 폴더 열기*.

## 2. 처음 시작 — 쓰던 엑셀 그대로 올리기
*가져오기 → 파일 올리기*에서 아래 파일을 하나씩 올립니다. 앱이 파일 종류를 알아서 구분합니다.
1. **2026 수입예산** (관·항·목·예산액, 전년 이월) → 수입 예산 + 전년도 이월금
2. **2026 지출예산** (순위·항목·년간 예산·비고) → 지출 예산, 지출 항목 순서·비고
3. **총입출금내역관리** (거래일시·내용·출금·입금·거래후 잔액·지출계정과목·비고·헌금종류·Month·현금입금)
   - 오프라인 헌금: 비고 '오프라인' 또는 거래일시가 빈 줄 → 주(Month)별 이름·종류
   - 온라인 입금: '문상재십일조', '고명길(십일조)'처럼 적힌 내용에서 교인 이름을 찾아 연결
   - 오프라인(현금)은 종류와 상관없이 주일 헌금으로(주차·회비·찬조 포함 — 현금입금 대조에 들어감). 온라인 4.기타헌금(교회사용료·월세·주차·이자 등)은 기타수입. 4.기타헌금은 기부금영수증 제외
   - 지출: 지출계정과목 = 지출예산 항목 이름
   - 현금입금 칸 → 주일별 오프라인 합계와 대조용 (수입에 다시 더하지 않음)
   - 같은 파일을 다시 올려도 같은 거래(거래일시+내용+금액)는 한 번만 들어갑니다. 이번 주 줄만 올려도 됩니다. 엑셀에서 지우거나 바꾼 통장 거래(파일이 담은 기간 안)는 미리보기에 ‘엑셀에서 없어진 거래’로 보이고 앱에서도 지워집니다(체크 해제 가능). 앱에서 지운 총입출금 거래는 기억해 두어 다시 올려도 들어오지 않습니다(*설정 → 지운 거래*에서 되살리기). 오프라인 헌금은 주(Month)별로 바꿀지 고릅니다.

**교인명단·주민번호**
- 교인명단(이름·직분·연락처·주소·구역)은 **교적관리 구글시트**가 원본입니다. *설정 → 교적관리 시트 연결*에 출석부 웹앱 URL·KEY를 넣고 *헌금자 명단 → 교적관리 시트에서 가져오기*. 시트는 읽기만 하고, 교인 ID로 연결합니다. 전출·소천·제명은 숨김 처리.
- 주민번호는 **이 앱에만** 저장합니다(교적관리 시트에 넣지 않음 — 출석부 동기화 때 지워지고 태블릿까지 노출됨). *헌금자 명단 → 주민번호 엑셀 불러오기*: 시트 이름·열 순서 무관, 머리글에 이름(성명)과 주민번호(또는 앞자리/뒷자리) 열. 명단에 있는 이름만 채우고 새로 추가하지 않습니다.

헌금종류 → 목 연결은 *설정 → 헌금종류 연결*에서 바꿉니다. 연결 안 된 종류·종류 빈칸은 '미분류'로 표시되고 합계에는 들어갑니다.

## 3. 매주
- **오프라인 헌금**: *주일 헌금 입력* — 이름 줄에 금액 입력(`3만`도 됨), Enter로 아래 칸. 자동 저장. 현금입금과 맞는지 바로 보입니다.
- **현금지출**: 받은 현금 헌금에서 통장에 넣기 전에 바로 쓴 돈은 지출 증빙을 **현금**으로. *주일별 헌금*에 현금지출 칸이 따로 나오고, 차이 = 오프라인 − 현금입금 − 현금지출. 차이 칸(또는 주일 헌금 입력의 *현금지출 확인*)을 누르면 그 주 지출 목록에서 체크로 현금 표시.
- **장부·통장 대조**: *현황 → 통장 잔액 → 내역* (또는 *주일별 헌금 → 장부·통장 대조*). 장부 잔액 − 통장 잔액 차이를 ① 손에 있는 현금(오프라인 − 현금입금 − 현금지출, 주별) ② 통장 잔액이 끊긴 곳(총입출금에 빠지거나 금액이 다른 거래, 엑셀 행 번호) ③ 이월금 차이 ④ 설명 안 되는 차이로 나눠 보여 줍니다. 거래일시 없는 지출은 현금지출로 봅니다(비고 ‘온라인’이면 통장 거래로 봄).
- **통장 입금 대조**: *주일별 헌금*의 ‘온라인’은 기부금영수증 대상 헌금만, ‘기타입금’은 주차·회비·찬조·이자·종류 빈칸 입금. 온라인(또는 기타입금) 금액을 누르면 그 주(Month) 통장 입금 전체를 거래일시 순으로 한 건씩 보여 주고(헌금자·종류 / 계정, 무명·미분류 표시) Excel로 받을 수 있습니다.
- **온라인 입금·지출**: 총입출금내역에 지금처럼 적고 다시 올리거나, *지출 · 기타수입*에서 직접 기록.
- 또는 구글 헌금집계 시트 주간 블록 가져오기 (공유 공개 시 바로, 비공개면 .xlsx로 받아 올리기)

## 4. 출력 (보고서 출력 메뉴, Excel·PDF)
| 출력물 | 내용 |
|---|---|
| 주간 헌금집계표 | 번호·이름·항목·합계·내용, 소계·총계·집계/재정부장/일자 줄 |
| 제직회 분기 재정보고 | 전기이월·당기수입·당기지출·차기이월, 관/항별 분기 실적·연누계·예산 대비, 주일별 헌금 (정관 제43조 2항) |
| 공동의회 예결산서 | 올해 예산·결산·차액·집행률 + 다음 해 예산(안)·증감, 감사 확인란 (정관 제43조) |
| 교인별 기부금영수증 | 별지 제45호의2서식 항목, 월별 헌금 합계, 일련번호 고정 + 발급명세 Excel |
| 지출 항목별 보고서 | 연간·분기·월 / 전체 또는 한 항목: 순위별 예산·실적·집행률·잔여 예산, 월별 지출표, 항목별 거래 상세 (Excel 상세는 한 줄 한 건, 필터 적용) |
| 지출결의서(송금 요청) | *송금 요청* 메뉴: 요청일·계정·금액·내용·받는 이·은행·계좌번호 → 결의서 PDF(여러 건 선택 시 한 장 목록으로), 목록 Excel. 장부(지출·예결산)에는 들어가지 않고, 같은 금액의 통장 출금이 들어오면 ‘출금 확인’ 표시 |
| 지출결의서 | 지출 기록을 열어 *지출결의서 PDF* (100만원 초과 시 운영위원회 회장 승인란, 정관 제44조) |

## 5. GitHub 자동 업데이트
1. GitHub에서 새 저장소 `seonghyeon-finance` (Public, README 추가하지 않음). 저장소에는 프로그램 코드만 올라가고 헌금 데이터는 올라가지 않습니다.
2. 이 폴더에서 `1_GitHub_first_upload.bat` → 저장소 주소 입력.
3. Actions 빌드(5~10분) 후 Releases의 설치 파일로 각 PC에 설치.
4. 새 버전: 코드 수정 후 `2_release_new_version.bat`.

## 6. 개발자용
```
npm install
npm start      # 실행
npm run dist   # 설치 파일 직접 만들기
python tools/make_template.py . renderer/assets/성현교회재정_기본양식.xlsx   # 계정과목(renderer/defaults.js) 바꾼 뒤 빈 양식 다시 만들기
```
파일: `main.js`(저장·PDF·파일), `renderer/core.js`(데이터·집계), `io.js`(가져오기), `reports.js`(출력물), `views.js`(화면), `defaults.js`(기본 계정과목·헌금항목).
